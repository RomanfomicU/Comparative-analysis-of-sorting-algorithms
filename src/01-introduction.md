# Введение

Сортировка — одна из наиболее изученных задач информатики. По оценке Д. Кнута,
значительная доля машинного времени исторически тратилась именно на упорядочивание
данных [@knuth1998]. Сортировка лежит в основе бинарного поиска, построения индексов
баз данных, удаления дубликатов и многих других алгоритмов.

Формально задача ставится так: дана последовательность $a_1, a_2, \ldots, a_n$
элементов множества с линейным порядком; требуется найти перестановку $\pi$, такую что

$$
a_{\pi(1)} \le a_{\pi(2)} \le \ldots \le a_{\pi(n)}.
$$

В работе рассматриваются только алгоритмы *сортировки сравнениями*, то есть такие,
которые получают информацию о входных данных исключительно через операцию
сравнения двух элементов. Для них естественной мерой трудоёмкости служит число
сравнений $C(n)$, не зависящее от конкретной машины и языка программирования.

**Цель работы** — сопоставить теоретические оценки числа сравнений и времени работы
четырёх классических алгоритмов с результатами измерений на реальной реализации.

Для достижения цели решаются следующие задачи:

1. привести асимптотические оценки трудоёмкости алгоритмов и нижнюю границу
   для класса сортировок сравнениями;
2. реализовать алгоритмы с подсчётом числа сравнений;
3. провести замеры на случайных массивах разного размера;
4. сравнить полученные значения с теоретическими.
